
# StockSentry

### Autonomous Equity Intelligence. Explainable Decisions. Verifiable Evidence

StockSentry is an equity intelligence platform designed to help investors, independent researchers, analysts and portfolio managers understand public-market opportunities through structured research, quantitative analysis, portfolio intelligence and risk oversight.

The platform brings multiple analytical capabilities into one workspace. Its long-term objective is to coordinate specialized AI agents, evaluate investment ideas, examine portfolio exposure, enforce risk policies and create an auditable record of analytical decisions.

StockSentry is being built around one central idea:

**Investment intelligence should be explainable, risk-aware and supported by evidence—not just generated by an AI model.**

---

## The Problem

Investment research is fragmented.

Investors often need to move between company filings, market data platforms, financial dashboards, spreadsheets, news sources and portfolio tools to understand a single investment opportunity.

This creates several problems:

- Research and portfolio information are scattered across different tools.
- Investment decisions can lack a clear explanation or supporting evidence.
- Quantitative analysis and qualitative research are often disconnected.
- Portfolio risks can be difficult to monitor consistently.
- AI-generated investment insights can be difficult to audit or reproduce.
- The reasoning behind a previous investment decision can become difficult to recover.

StockSentry aims to bring these activities into one coordinated intelligence environment.

## The Solution

StockSentry combines several analytical capabilities:

1. **Equity Research:** Organize company research, financial information, investment theses and supporting sources.
2. **Quantitative Analysis:** Evaluate market signals, financial metrics and analytical models.
3. **Portfolio Intelligence:** Understand holdings, allocations, concentration and portfolio performance.
4. **Risk Oversight:** Identify portfolio exposure, concentration risks and policy violations.
5. **Multi-Agent Research:** Coordinate specialized agents responsible for different analytical tasks.
6. **Decision Ledger:** Preserve analytical decisions, supporting evidence and verification metadata.
7. **Verifiable Evidence:** Build toward cryptographic evidence records and optional on-chain verification.

The goal is to make the process behind an investment insight visible and reviewable.

## Who StockSentry Is For

StockSentry is being designed for:

- **Individual investors** who want a more structured approach to equity research.
- **Independent analysts** who need to organize company research and analytical findings.
- **Portfolio managers** who need visibility into holdings, allocation and risk.
- **Quantitative researchers** who want to combine analytical models with research workflows.
- **Investment research teams** that need a traceable record of analytical activity.
- **Developers and AI researchers** exploring specialized financial agents and verifiable AI workflows.

StockSentry is an analytical and research platform. It is not currently a brokerage, exchange, custodian or automated trade execution system.

### 2. Research

A dedicated workspace for company research, ticker exploration, research reports, investment theses and supporting evidence.

### 3. Portfolio

### 4. Agent Network

A coordinated environment for specialized analytical agents:

- Research Agent
- Quant Agent

- Risk Guardian

### 5. Risk Center

A dedicated risk oversight workspace for portfolio exposure, risk metrics, concentration analysis and policy checks.

### 6. Decision Ledger

A record of analytical decisions, agent activity, evidence and verification status.

## The Agent Model

StockSentry is designed around specialized agents rather than one general-purpose AI assistant.

Each agent has a defined responsibility, input requirements, output structure and execution history.

The intended workflow is:

1. Receive an analytical request.
2. Collect relevant market and company information.
3. Perform research and quantitative evaluation.
4. Construct or evaluate portfolio scenarios.
5. Run risk and policy checks.
6. Record the result and supporting evidence.
7. Preserve the decision for later review.

Agent outputs should be structured, traceable and subject to validation.

## Development Principles

StockSentry follows these principles:

1. **Explainability:** Analytical results should include their reasoning and supporting evidence.
2. **Traceability:** Important analytical actions should be recorded.
3. **Risk awareness:** Portfolio and investment analysis should consider risk, not only potential returns.
4. **Modularity:** Each analytical capability should be independently maintainable.
5. **Data integrity:** Financial values, source information and analytical records should be handled carefully.
6. **Security:** Credentials, user information and financial data must be protected.
7. **Honest system status:** Demonstration data must never be presented as live financial information.
8. **Human oversight:** AI-generated analysis should not be mistaken for guaranteed investment advice.

## Getting Started

### Requirements

- Node.js
- npm
- Git
- PostgreSQL when database functionality is configured

### Frontend

From the project root:

```bash
npm install
npm run dev
```

The Vite development server normally runs at:

```text
http://localhost:5173
```

### Backend

Open another terminal:

```bash
cd server
npm install
npm run dev
```

The API normally runs at:

```text
http://localhost:4000
```

### Health Check

```text
GET http://localhost:4000/api/v1/health
```

The current health endpoint verifies that the API process is responding. Database connectivity is not yet part of the health check.

### Environment Variables

The backend uses a local `.env` file.

Example:

```env
PORT=4000
NODE_ENV=development
FRONTEND_URL=http://localhost:5173
DATABASE_URL=
DATABASE_SSL=false
```

Never commit actual credentials or API keys.
